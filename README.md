# UP5-Entrega-EDE---Repositorio-de-GitHub
Creacion y contribucion de repositorios de github

## Enunciado de Aules
- La primera es colaborar en el repositorio recetas-cocina con una pull request.
- La segunda es parte del proyecto intermodular. ¡NO OLVIDEIS INVITARME A VUESTRO REPO PRIVADO!. Si en la estructura de carpeta algo no os encaja, meter un .txt y comentarlo (por ejemplo habla de una landing que todavía no hemos construido, dejad el .txt y ya lo reemplazaremos). ¡No subáis videos a github, sólo enlaces!. Se esperan mínimo 2 commits.
